# Enhancement Roadmap — Missing Excalidraw Features

## Priority 1 — Core UX (High Impact)

| Feature | Description | Complexity |
|---------|-------------|------------|
| **Sticky Notes** | Draggable colored note cards — signature Excalidraw feature | Medium |
| **Resize Handles** | Drag handles on selected shapes to resize proportionally | Medium |
| **Rotation Handle** | Rotate shapes with a rotation handle on selection | Medium |
| **Snap to Grid** | Align shapes to a configurable grid | Low |
| **Alignment Guides** | Smart guides showing alignment to other shapes when dragging | Medium |
| **Layers / Z-index** | Bring forward / send backward / bring to front / send to back | Medium |
| **Right-click Context Menu** | Copy, paste, delete, duplicate, layer order, group/ungroup | Medium |
| **Duplicate (Ctrl+D)** | Quick duplicate of selected shapes | Low |

## Priority 2 — Productivity (Medium Impact)

| Feature | Description | Complexity |
|---------|-------------|------------|
| **Arrow Binding** | Arrows snap/attach to shape edges, follow when moved | High |
| **Arrow Labeling** | Add text labels on arrows | Low |
| **Text Formatting** | Bold, italic, font size, font family selection | Medium |
| **Multi-point Lines** | Click-to-add-points polyline drawing | Medium |
| **Libraries** | Save/load/share reusable shape collections | High |
| **Frames** | Group and name regions of the canvas | Medium |
| **Minimap** | Small overview navigator for large canvases | Medium |
| **Search / Find (Cmd+F)** | Find shapes by text content | Medium |
| **Custom Fonts** | Multiple font options beyond default | Low |

## Priority 3 — Advanced (Lower Impact)

| Feature | Description | Complexity |
|---------|-------------|------------|
| **Mermaid to Diagram** | Convert Mermaid text syntax to shapes | High |
| **Slideshow / Presentation** | Frames become slides, present mode | High |
| **Embed Web Links** | Attach URLs to shapes, open on click | Low |
| **Image Cropping** | Crop embedded images after insertion | Medium |
| **SVG Paste** | Paste SVG directly onto canvas | Medium |
| **Collaboration Cursors** | See other users' cursors in real-time | High |
| **Voice Hangouts** | In-app voice/video chat | High |
| **Trash / Recovery** | Soft-delete with restore from trash | Medium |
| **Collaboration Permissions** | View-only, edit, admin roles | Medium |
| **Scene Versioning** | Named versions/snapshots | High |
| **Laser Pointer** | Temporary visible pointer for presentations | Low |
| **Plugin / Extension System** | Load custom tools | High |

## Priority 4 — Quick Wins (Easy to Add)

| Feature | Description | Complexity |
|---------|-------------|------------|
| **Align Left/Right/Center** | Align multiple selected shapes | Low |
| **Distribute Spacing** | Evenly distribute shapes horizontally/vertically | Low |
| **Lock Shapes** | Prevent accidental movement of locked shapes | Low |
| **Eye Dropper** | Pick color from canvas | Low |
| **Keyboard Shortcuts Panel** | Show all available shortcuts | Low |
| **Canvas Background Options** | Dot grid, cross grid, or plain background | Low |
| **Zoom to Fit** | Fit all shapes in viewport (Ctrl+Shift+1) | Low |
| **Arrow Key Navigation** | Arrow keys to nudge selected shapes | Low |
| **Ellipsis Arc** | Partial arc circles | Low |
| **Constant-Width Pen** | Uniform stroke width freedraw mode | Low |

---

## Suggested Implementation Order

1. **Quick Wins** — Start here for fast visible improvements
2. **Priority 1** — Core UX that makes it feel like a real whiteboard
3. **Priority 2** — Productivity features for power users
4. **Priority 3** — Advanced features for differentiation
